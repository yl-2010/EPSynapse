Groq key

Chat does not take a key in the pill. Save a free Groq key on your Google account first, then ask.

How to get a key

  1. Open console.groq.com/keys. Sign up with Google, GitHub, or email. The free tier does not ask for a card.
  2. Click Create API Key. Name it EPSynapse or whatever you will recognize. Submit.
  3. Copy the key now. It starts with gsk_. Groq shows the full value only once.

Where to paste it

  1. Come back to epsynapse.com and sign in with Google.
  2. Tap the gear in the bottom-left corner.
  3. Tap Chat key.
  4. Paste the gsk_ key in the API key field. Leave Model on Groq.
  5. Tap Save key. Enter also saves. Do not use the School Save button for this.
  6. You should land back on the settings list. Chat key must say Groq, not "Add a Groq key".
  7. Close settings. Open the chat pill and ask something. Homework, a class, Canvas, the day.

Where the key lives

The key is stored on your Google account. Chat reads it from there. It is not in the public site files, and it is not read from the chat box.

If you lose it, make a new one on the same Groq keys page and tap Save key again.
