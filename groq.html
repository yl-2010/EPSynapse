Groq key

Chat needs a free Groq API key. Get one, then paste it into EPSynapse Settings. Settings is the gear on the home screen after you sign in with Google.

How to get a key

  1. Open console.groq.com and sign up. Google, GitHub, or email works. The free tier does not ask for a card.
  2. Open console.groq.com/keys. That is API Keys in the left nav.
  3. Click Create API Key. Name it EPSynapse or whatever you will recognize. Submit.
  4. Copy the key now. It starts with gsk_. Groq shows the full value only once.
  5. Come back to EPSynapse Settings, paste it in the API key field, and save.

Where the key lives

The key stays in this browser. EPSynapse does not put it in the public site files.

If you lose it, make a new one on the same Groq keys page.
