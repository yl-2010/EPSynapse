School

    Upload this trimester's four11 schedule so your classes and grades can line up. Use the printed term card with periods A-H from after the latest add/drop, the same classes you have in Canvas right now. EPSynapse syncs schedule, classes, and grades with Canvas, so the PDF you add has to match.

    Chat key

    1. Sign in with Google on this page if you have not already.
    2. Get a free Groq key at console.groq.com/keys. Sign up with Google. No credit card. Create API Key, then copy the value that starts with gsk_. Groq shows it only once.
    3. Paste it in the API key field below. Leave Model on Groq.
    4. Tap Save key. Enter also saves. Do not use the School Save button for this.
    5. You can add more than one key. If one hits its free limit, chat switches to the next on its own.
    6. Chat key on the settings list must say Groq. Then close settings and ask in the chat pill. Do not paste the key in chat.
    7. If chat stops, Groq usually rejected the key or hit the free limit (about 1000 chats a day). A new key on the same Groq login does not reset a daily cap. Create a key at console.groq.com/keys, tap Add another, Save key. Or wait. Or switch Model to Gemini. Full steps.

      Canvas

      1. Sign in with Google on this page if you have not already.
      2. Open eastsideprep.instructure.com. If you see four11, tap @eastsideprep.org login. Sign in with your school Microsoft account. Not Parent/Guardian.
      3. In Canvas, click Account (your picture, left side), then Settings. Scroll to Approved Integrations. Click Add New Access Token.
      4. Purpose: EPSynapse. Students must pick an expiration date. There is no permissions list. Click Generate Token and copy it now. Canvas shows it once.
      5. Leave Canvas URL as https://eastsideprep.instructure.com unless you use another school. Paste the token below. Tap Save.
      6. Canvas on the settings list must say Connected. Then close settings.

      OneDrive

      1. Tap Connect. A Microsoft window opens. Sign in with your @eastsideprep.org account.
      2. If Microsoft says "Approval required" or "Need admin approval", that is expected. Come back here and tap Send request to school IT.
      3. Once IT approves, tap Connect again. The pane says Connected only after EPSynapse can actually read your OneDrive files.
